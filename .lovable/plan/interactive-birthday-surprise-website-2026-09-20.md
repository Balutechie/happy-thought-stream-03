# Interactive Birthday Surprise Website

## Experience
- Replace the blank home screen with a mobile-first birthday surprise matching the uploaded video’s pink retro-computer style.
- Begin with the playful “I made something special for you… wanna see it?” prompt, including working **Yes** and teasing **No** interactions.
- Reveal three memory screens in sequence using the uploaded GIFs in this order: cake, dancing Hello Kitty, gift cat.
- Finish with the “Happy Birthday, Birthday Star” reveal and a scrollable birthday letter signed **Someone who cares**.

## Visual direction
- Recreate the reference’s bright pink window frames, soft pastel background, pixel details, compact mono text, handwritten-style headings, hearts, sparkles, and playful transitions.
- Keep the experience polished on the current phone-sized view while adapting cleanly to larger screens.
- Preserve the GIF animations and frame each one like the image windows shown in the video.

## Interaction and motion
- Add smooth scene transitions, button press feedback, subtle floating decorations, and staged text reveals.
- Make every control keyboard-accessible and respect reduced-motion preferences.
- Keep all content in one focused interactive flow without logins, forms, or stored data.

## Content
- Use polished wording closely matching the visible reference video.
- Use short matching captions for each memory and a warm complete birthday letter.
- Use “Birthday Star” as the recipient wording because no personal name was supplied.

## Technical details
- Build the experience in the existing browser app using React-rendered HTML, CSS/Tailwind styling, and JavaScript interactions.
- Store the three uploaded GIFs through the project’s media asset flow and reference them from the page.
- Add page-specific title, description, and social metadata.
- Verify the full sequence and layout at mobile and desktop sizes after implementation.
